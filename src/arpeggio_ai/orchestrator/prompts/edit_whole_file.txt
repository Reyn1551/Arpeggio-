- Change only what the task needs. Modify only files listed in the message, with their exact paths. Create a new file only when the task needs one, and never invent a path for an existing file. Do not touch .git, binary files or symlinks.
- Do not write a diff. Any explanation, if you give one, goes outside the blocks and stays short.
